# Key Features

### Peer-to-Peer Video Calling with WebRTC

Connectify uses WebRTC to establish a direct peer-to-peer video and audio connection between users. This allows real-time communication between users without sending the media through the application server.

### Real-Time Signaling via WebSocket

WebSocket is used for the signaling process during video calls. It helps exchange connection information such as offers, answers, and ICE candidates between users.

### Secure Authentication with JWT and Cookies

Authentication is handled using JSON Web Tokens (JWT) stored in HTTP-only cookies. This provides a secure way to maintain authenticated user sessions.

### Email-Based User Discovery and Requests

Users can find other users using their email address and send connection requests. Users can accept, reject, or manage connection requests.

### Cloud and Container Support

The project includes Docker and Cloudflare-related technologies, supporting modern deployment and infrastructure requirements.

# Project

**Connectify The World** is a web-based real-time communication application that allows users to connect with each other and communicate through video and audio calls.

The project is built using modern web technologies including React, TypeScript, Node.js, Express.js, MongoDB, WebSocket, and WebRTC.
